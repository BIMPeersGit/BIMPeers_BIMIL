# Transfer

Transfer moves the objects you select onto a slot's layer — a fast way to send elements to the right layer without opening the layer manager.

Run it from the **Transfer** ribbon drop-down item (or the `QLT` command).

### How to use

1. **Select** the objects to move (or pre-select them before running).
2. Run **Transfer**, or type `QLT`.
3. **Enter the slot number** (0–9) when prompted.

The selected objects are moved onto that slot's layer.

### Notes

* **Slot 0** means the **current layer** — use it to send objects to whatever layer is current.
* Slots 1–9 must hold a layer that exists in the drawing; if the slot is empty or its layer is missing, Transfer reports it and stops.
