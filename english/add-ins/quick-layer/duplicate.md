# Duplicate

Duplicate copies the objects you select and places the copies on a slot's layer, leaving the originals exactly where they are. It is handy for creating a layer-swapped copy of an element in one step.

Run it from the **Duplicate** ribbon drop-down item (or the `QLD` command).

### How to use

1. **Select** the objects to copy (or pre-select them before running).
2. Run **Duplicate**, or type `QLD`.
3. **Enter the slot number** (0–9) when prompted.

The objects are copied in place, and the copies are moved onto that slot's layer. The originals are unchanged.

### Notes

* **Slot 0** means the **current layer**.
* Slots 1–9 must hold a layer that exists in the drawing; if the slot is empty or its layer is missing, Duplicate reports it and stops.
