# Version History

#### v1.0.0.0 (Private Preview)

* Initial private preview of Table Paste.
* Added clipboard table detection for Excel XML, HTML, and RTF table data.
* Added native AutoCAD table insertion with source sizes, merged cells, colors, fonts, borders, padding, and alignment.
* Added scale, text style, table layer, anchor corner, live placement preview, and reusable saved settings.
