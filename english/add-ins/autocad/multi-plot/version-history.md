# Version History

#### v1.0.0.0 (Private Preview)

* Initial private preview of Multi Plot.
* Added batch plotting for matching frames across multiple DWG files.
* Added reference frame detection from the current drawing or a selected reference DWG.
* Added DWG queue management with frame counts, per-file copies, status tracking, and skipped-file reporting.
* Added AutoCAD page setup reuse, output folder selection, PDF/file output handling, and plotting progress feedback.
